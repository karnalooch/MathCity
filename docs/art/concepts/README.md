## Instrukcja tworzenia dalszych obrazów

1. Otwórz [VISUAL_REFERENCE_ATLAS.md](../VISUAL_REFERENCE_ATLAS.md) i znajdź wybrany V-ID.
2. Przeczytaj [SHOT_CARDS_V01_V23.md](../SHOT_CARDS_V01_V23.md), [STYLE_VARIANTS.md](../STYLE_VARIANTS.md), [CONCEPT_PROMPT_LIBRARY.md](../CONCEPT_PROMPT_LIBRARY.md), uwzględnij źródła.
3. Dla porównań C01/N01 generuj **trzy style przy zablokowanym kadrze**; nie porównuj obrazów o innych obiektach i perspektywie.
4. Pliki JPG/PNG/WebP dodaj dopiero po rzeczywistym stworzeniu i obejrzeniu, pod nazwą `V02_S1_day_v01.png` itp.
5. Dopisz do manifestu: źródła wejściowe i status licencji, narzędzie, datę, prawa do obrazu, cel, wynik QA i decyzję właściciela.
6. **Nie kopiuj cudzych zdjęć, nie umieszczaj realnych twarzy dzieci**, nie przedstawiaj AI jako fotografii czy screenshotu Roblox.
7. Brak generatora = `PROMPT_READY_IMAGE_NOT_GENERATED`; **SVG_CONCEPT_GUIDE** nie oznacza `RENDERED_CONCEPT` docelowego V-ID.
