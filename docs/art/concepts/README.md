## Zasady użycia
- Każdy obraz = identyfikator kadru Vxx, styl S1/S2/S3, pora dnia L1/L2/L3, wersja vNN.
- Każdy obraz ma manifest w tym pliku: nazwa, narzędzie, data, źródło użytych danych, prawa wejścia/wyjścia, status, ocena i link do karty Vxx.
- `AI_CONCEPT` nie jest zdjęciem, `UNREAL_RENDER` nie jest screenshotem Roblox, `ROBLOX_SCREENSHOT` wymaga rzeczywistego ujęcia z Roblox.
- Obrazy wielkoformatowe publikuj tylko jeśli to sensowne dla PR; preferuj przeglądowe JPG/PNG/WebP z rozsądnym rozmiarem, bez wbudowanych cudzych materiałów.
- Zdjęć rzeczywistych dzieci lub nieautoryzowanych fragmentów galerii nie commituj.
- Jeśli generator obrazu jest niedostępny, nie umieszczaj pustych plików ani wymyślonych odnośników.
