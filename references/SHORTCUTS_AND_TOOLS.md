# ⌨️ Ściągawka: Skróty Klawiszowe i Narzędzia Roblox Studio

Zbiór najważniejszych skrótów klawiszowych i porad, które przyspieszą budowanie wieży i miasta!

---

## 1. Narzędzia Przekształceń (Górny Pasek)

| Klawisz | Narzędzie | Działanie |
| :---: | :--- | :--- |
| **`1`** | **Select (Zaznaczanie)** | Pozwala klikać i przeciągać obiekty. |
| **`2`** | **Move (Przesuwanie)** | Wyświetla kolorowe strzałki (X, Y, Z) do precyzyjnego przesuwania. |
| **`3`** | **Scale (Skalowanie)** | Wyświetla kulki do rozciągania i zmniejszania klocków. |
| **`4`** | **Rotate (Obracanie)** | Wyświetla pierścienie do obracania obiektów o określony kąt. |

---

## 2. Najważniejsze Skróty Klawiszowe

| Skrót | Działanie | Dlaczego to ważne? |
| :--- | :--- | :--- |
| **`Ctrl + D`** | **Duplikuj (Duplicate)** | Kopiuje zaznaczony klocek lub całe piętro dokładnie w tym samym miejscu. Podstawa szybkiego budowania wieży! |
| **`Ctrl + G`** | **Grupuj jako Model** | Łączy zaznaczone klocki w jeden model (np. `Floor1`). |
| **`Ctrl + U`** | **Rozgrupuj (Ungroup)** | Rozbija model na pojedyncze klocki. |
| **`Alt + A`** | **Przełącz Anchored** | Włącza/wyłącza zakotwiczenie klocka, aby nie spadał pod wpływem grawitacji. |
| **`Ctrl + Z`** | **Cofnij (Undo)** | Cofa ostatni ruch lub pomyłkę. |
| **`Ctrl + Y`** | **Ponów (Redo)** | Ponawia cofniętą akcję. |
| **`F`** | **Skup kamerę (Focus)** | Po zaznaczeniu obiektu w Explorerze wciskasz `F` i kamera natychmiast leci prosto do niego! |

---

## 3. Testowanie Gry

| Skrót | Funkcja |
| :---: | :--- |
| **`F5`** | **Play (Graj)** – uruchamia grę z Twoją postacią w miejscu spawnu. |
| **`Shift + F5`** | **Stop** – zatrzymuje testowanie i wraca do edytora. |
| **`F8`** | **Run (Uruchom)** – włącza fizykę i skrypty bez dołączania postaci gracza (świetne do testowania działania drzwi i mechanizmów). |

---

## 4. Co zrobić, gdy znikną okna Explorer lub Properties?
1. Na samej górze Roblox Studio kliknijcie zakładkę **View** (Widok).
2. Po lewej stronie upewnijcie się, że podświetlone są dwa pierwsze przyciski:
   * 🗂️ **Explorer** (Drzewo wszystkich obiektów w grze)
   * ⚙️ **Properties** (Właściwości zaznaczonego klocka: rozmiar, kolor, materiał)
